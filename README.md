# Сайт преподавателя Соловцевой И.А. — инструкция по развёртыванию и правкам

Готовый статический сайт по ТЗ «Техническое задание и контент» (дизайн: **«Сетевая топология»** + bento-плитки главной + светлые контентные страницы + точечные «консольные» акценты на страницах ПМ). Исходный сайт — в папке `site/`.

## 1. Что внутри (структура папки `site/`)

```
site/
├── index.html            — Главная (hero, показатели, узлы, новости, CTA)
├── about.html            — Обо мне (путь, образование, награды, подход)
├── disciplines.html      — Дисциплины 09.02.06 (карточки-порты ПМ/ОП)
├── disciplines/
│   ├── pm-01.html        — ПМ.01 Настройка сетевой инфраструктуры
│   ├── pm-02.html        — ПМ.02 Организация сетевого администрирования ОС
│   └── pm-03.html        — ПМ.03 Эксплуатация операционных систем
├── materials.html        — Учебные материалы (фильтры + поиск)
├── projects.html         — Проекты студентов (+ таблицы результатов)
├── method.html           — Методическая работа (ПК, выступления, жюри)
├── contacts.html         — Контакты + форма обратной связи
├── css/style.css         — единый файл стилей (цвета, шрифты — в начале файла)
├── js/main.js            — меню, фильтры материалов, форма
├── files/                — PDF-файлы материалов (сейчас заглушки!)
├── img/                  — фотографии (пока пусто, см. п.3.4)
├── .htaccess             — UTF-8, кэш, красивые URL
├── robots.txt            — для поисковиков
└── sitemap.xml           — карта сайта
```

## 2. Как развернуть и опубликовать сайт на Beget (по шагам, с учётом реальной панели)

> Важно: папки `www` у вас в корне нет и быть не должно — она **появится автоматически** после создания сайта в панели Beget. Всё, что нужно загрузить, лежит в папке `site/` этого репозитория.

### Шаг 1. Регистрация и создание сайта
1. Зарегистрируйтесь на [beget.com](https://beget.com), войдите в **панель управления** (IP-панель) — она открывается по ссылке «Панель управления» из письма после регистрации.
2. На главной панели вы увидите вкладки/разделы: **«Сайты»**, **«Домены»**, **«FTP»**, **«MySQL»**, **«Локальный сервер»**, **«Удалённый сервер»**, **«SSL»**, **«Почта»** и др. Вам понадобятся только **«Сайты»** (иногда называется «Мои сайты» / «Список сайтов»), **«Домены»** и **«Файлы»**. Разделы «Локальный сервер» и «Удалённый сервер» (SSH) для статического сайта **не нужны** — их не трогаем.
3. Во вкладке **«Сайты» → «Добавить сайт»** создайте сайт:
   - **Вариант А (быстрый, бесплатный, без покупки домена):** в поле домена введите любое короткое имя, например `solovceva`, и в выпадающем списке зон выберите `beget.app` (альтернативные бесплатные зоны — `beget.tech`, `my1.ru`, `pointhosting.ru`). Сайт создаётся за минуту.
   - **Вариант Б (свой домен):** сначала во вкладке **«Домены» → «Регистрация доменов»** купите домен (например, `solovceva.ru`) либо добавьте уже купленный у другого регистратора и направьте его DNS на NS-серверы Beget (`ns1.beget.com`, `ns2.beget.com`). Затем во вкладке «Сайты» → «Добавить сайт» укажите этот домен.
4. После создания сайта во вкладке **«Сайты»** появится строка с вашим доменом. На этом этапе на сервере автоматически создаётся **корневая папка сайта** — путь к ней: `/home/ВАШ_ЛОГИН/public_html/ВАШ_ДОМЕН/www/`. Именно эта папка `www` и есть корень вашего будущего сайта.

### Шаг 2. Узнать адрес сайта (где смотреть)
- Публичный адрес сайта виден во вкладке **«Сайты»** напротив домена (столбец «Адрес»/«URL») и в письме об активации. Он всегда одного из видов:
  - `https://solovceva.beget.app` — если выбрали бесплатную зону;
  - `https://ваш-домен.ru` — если используете свой домен.
- Этот же адрес продублирован в разделе **«Домены»** и в SSL-виджете на главной панели. Запомните/сохраните его — он нужен для проверки публикации и для файлов `robots.txt`/`sitemap.xml` (Шаг 5).

### Шаг 3. Загрузка файлов сайта в корень (`www`)
**Вариант А — Файловый менеджер (проще всего):**
1. Панель Beget → раздел **«Файлы» → «Файловый менеджер»**.
2. Перейдите по пути: `public_html` → `ВАШ_ДОМЕН` → `www`. (Если файловый менеджер открылся в домашней папке `/home/логин` — спускайтесь слева по дереву именно туда.)
3. **Удалите в `www` дефолтный файл `index.php`** — это стандартная заглушка Beget, она перекроет вашу главную страницу.
4. Загрузите **содержимое** папки `site/` (не саму папку `site`, а всё, что внутри: `index.html`, `about.html`, `contacts.html`, `disciplines.html`, `materials.html`, `method.html`, `projects.html`, `css/`, `js/`, `files/`, `img/`, `disciplines/`, `robots.txt`, `sitemap.xml`, `.htaccess`) прямо в `www`.
5. ⚠ Файл `.htaccess` — скрытый: включите в файловом менеджере «Показывать скрытые файлы» (иконка глаза / настройка вида), иначе он не загрузится.

**Вариант Б — через zip-архив (надёжнее для `.htaccess`):**
1. На компьютере упакуйте **содержимое** папки `site/` в архив `site.zip` (внутри архива должны лежать `index.html`, `css/`… а не папка `site/`).
2. Файловый менеджер → откройте `www` → «Загрузить» → выберите `site.zip` → правый клик по архиву → **«Распаковать»** (извлечь в текущую папку) → удалите архив и дефолтный `index.php`.

**Вариант В — по FTP (FileZilla), если удобнее:**
1. Панель → вкладка **«FTP»** (или «FTP-доступ»): создайте FTP-пользователя, скопируйте **хост** (он указан на этой же странице, обычно совпадает с адресом сайта), **логин** и **пароль**.
2. В FileZilla: «Хост» = адрес из панели, логин/пароль — ваши, порт 21, протокол FTP. Подключившись, вы окажетесь в `/home/логин`; перейдите в `public_html/ВАШ_ДОМЕН/www` и перетащите туда содержимое `site/`. Включите показ скрытых файлов («Сервер → Принудительно отображать скрытые файлы»), чтобы передать `.htaccess`.

### Шаг 4. Проверка публикации
Откройте адрес из Шага 2 (например, `http://solovceva.beget.app`) — должна загрузиться главная страница сайта. Если вместо неё серая страница Beget: проверьте, что удалили `index.php` и что файлы лежат именно в `www`, а не вложенной папкой.

### Шаг 5. HTTPS (зелёный замок)
1. Панель → раздел **«SSL»** (или «Домены» → ваш домен → «SSL-сертификаты»).
2. Нажмите **«Установить бесплатный Let's Encrypt»** для вашего домена, дождись окончания выпуска (1–5 минут).
3. Включите переключатель **«Принудительный редирект с HTTP на HTTPS»**.
4. Теперь сайт доступен по `https://ваш-адрес` — этот адрес и публикуйте в резюме/подписях.

### Шаг 6. SEO-доводка
1. В файлах `robots.txt` и `sitemap.xml` замените `ВАШ-ДОМЕН` на реальное имя домена из Шага 2 (например, `solovceva.beget.app`) — это можно сделать прямо в файловом менеджере Beget («Редактировать») или на компьютере и перезагрузить файл.
2. Зарегистрируйте сайт в [Яндекс.Вебмастере](https://webmaster.yandex.ru) и Google Search Console, отправьте sitemap (`https://ваш-адрес/sitemap.xml`).
3. Favicon: положите `favicon.ico` в корень `www`.

### Шаг 7. Резервное копирование (требование ТЗ)
- Beget делает ежедневные автоматические бэкапы (раздел «Резервные копии», хранение ~7 дней).
- Дополнительно раз в месяц скачивайте папку `www` архивом к себе на компьютер / Яндекс.Диск.

### Частые вопросы при публикации
- **«В корне нет папки www»** — она не может быть видна до создания сайта: сначала «Сайты → Добавить сайт», затем `public_html/домен/www` появится в файловом менеджере.
- **«Открывается серая страница Beget вместо сайта»** — удалён не был `index.php` либо файлы заложены вложенной папкой (`site/index.html` вместо `index.html`). Файлы должны лежать непосредственно в `www`.
- **«Картинки/стили не грузятся»** — проверьте, что папки `css/`, `js/`, `img/` загружены в тот же `www`, что и `index.html`, имена регистрозависимы.
- **«Где посмотреть адрес сайта»** — вкладка «Сайты» (столбец URL), дублируется в письме об активации и в разделе «Домены».

## 3. Как вносить правки без программиста

Все правки — обычный текст внутри HTML-файлов. Редактируйте **Блокнотом**, **Notepad++** или **VS Code** (сохраняйте в кодировке UTF-8!), затем загружайте изменённый файл тем же способом (файловый менеджер / FTP). Перед правкой сохраняйте копию файла.

### 3.1 Добавить новый учебный материал
Откройте `materials.html`, найдите `<div id="materials-grid">` и скопируйте в конец типовую карточку, изменив текст и ссылку:

```html
<div class="mat-card" data-type="pdf" data-disc="ОП.05">
  <div class="mat-icon t-pdf">PDF</div>
  <div><h3>Название материала</h3><span class="tag">ОП.05 · РП</span><br>
  <a class="dl" href="files/imya-fayla.pdf" download>Скачать →</a></div>
</div>
```
- `data-type` — тип для фильтра: `pdf | pres | lab | test | note | doc`;
- файл положите в папку `files/` (имя — латиницей, без пробелов);
- для больших файлов — залейте на Яндекс.Диск (общий доступ «кто знает ссылку») и вставьте ссылку:
  `<a class="dl" href="https://disk.yandex.ru/d/XXXX" target="_blank">Открыть на Яндекс.Диске →</a>`

### 3.2 Добавить новость/достижение на главную
В `index.html` найдите `<div class="news-list">` и добавьте строку:
```html
<div class="news-item"><time>2026-09</time><div>Текст события.</div></div>
```

### 3.3 Изменить тексты обращения и «Обо мне»
Все личные тексты уже ввёрстаны, править их можно прямо в HTML:
- **Первый экран (обращение)** — `index.html`, блок `<div class="hero-greeting">…</div>` (три абзаца) и `<h1>`/`<p class="subtitle">` над ним;
- **Карточка-продолжение обращения** — `index.html`, `<div class="prose-card">` сразу после hero;
- **«О работе кратко»** — два блока «О пути» / «О том, как я учу» в `index.html` (класс `about-duo`);
- **«О студентах и результатах»** — `index.html`, карточка `prose-card` после списка новостей;
- **«Что вы найдёте на сайте»** — список `<ul class="find-list">` на главной и в `about.html`;
- **Финальный призыв** — `index.html`, блок `<div class="cta-band">` (тексты в `<p class="cta-text">`);
- **Страница «Обо мне»** — полный текст-размышление в `about.html`, раздел 1 (блок `<div class="essay">`), далее «О студентах», «Что вы найдёте», путь по годам, образование, награды, подход, школьный опыт и «Приглашение».
Стилы этих блоков: `.hero-greeting`, `.prose-card`, `.about-duo`, `.find-list`, `.cta-text`, `.essay` в `css/style.css`.

### 3.4 Добавить дисциплину
В `disciplines.html` скопируйте блок `<div class="port-card">…</div>`:
- для ПМ используйте класс `badge-pm`, для ОП — `badge-op`;
- отдельная страница модуля: скопируйте `disciplines/pm-02.html` → `pm-XX.html`, поменяйте тексты, в карточке укажите `href="disciplines/pm-XX.html"`, добавьте страницу в `sitemap.xml`.

### 3.5 Поставить фотографию
1. Положите портрет в `img/photo.jpg` (~800×1000 px, до 300 КБ).
2. В `index.html` в hero замените `<div class="hero-photo">…заглушка…</div>` на:
```html
<img class="hero-photo" src="img/photo.jpg" alt="Соловцева Инна Александровна" style="object-fit:cover">
```

### 3.6 Заменить PDF-заглушки на реальные документы
В `files/` лежат пустые PDF-заглушки. Замените каждый своим файлом, **сохранив имя**: `wp-op-07.pdf`, `wp-op-06.pdf`, `wp-mdk-01-01.pdf`, `wp-mdk-01-02.pdf`, `wp-mdk-02-01.pdf`, `kim-tsi.pdf`, `kim-op-04.pdf`. Либо поменяйте ссылки в `materials.html`.

### 3.7 Изменить цвета/шрифты
На сайте **одна цветовая тема — сине-фиолетовая**, переключателя тем нет (кнопки 🟢/🟣 из шапки удалены). Все цвета заданы один раз в начале `css/style.css` в блоке `:root`:
```css
--accent-strong: #6D28D9;   /* основной фиолетовый (кнопки, акценты) */
--accent-second: #2563EB;   /* синий (второй акцент, ссылки-теги) */
--hero-bg: linear-gradient(150deg, #EEF1FE 0%, #E9E4FF 45%, #DDE7FF 100%);
--footer-bg: #241B4D;       /* подвал */
```
Поменяли значение — обновился весь сайт. Шрифты (Unbounded, Golos Text, JetBrains Mono) подключаются ссылкой Google Fonts в `<head>` каждой страницы. В HTML-файлах на `<html …>` осталась метка `data-theme="violet"` — она безвредна и ни на что не влияет (все правила теперь в `:root`), удалять её не обязательно.

### 3.8 Телефон / e-mail / график консультаций
Левая колонка `contacts.html` (строки `E-mail`, `Телефон`, `График консультаций`). E-mail формы также указан в `js/main.js` (`mailto:inna742@ya.ru`).

### 3.9 Курс и форма обучения на страницах ПМ
В `disciplines/pm-0X.html` в блоке «Общая информация» есть ячейки с комментариями `<!-- укажите нужный -->` — замените значения на реальные.

### 3.10 Форма обратной связи
Сейчас форма работает без сервера: собирает письмо и открывает почтовую программу посетителя (mailto). Для отправки «на сервер» на Beget можно подключить PHP-обработчик или бесплатный сервис Formspree/FormSubmit — дорабатывается по запросу.

## 5. Локальный просмотр (до загрузки)
Просто откройте `site/index.html` двойным щелчком в браузере — сайт статический, интернет нужен только для загрузки шрифтов Google Fonts.
