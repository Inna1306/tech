# Сайт преподавателя Соловцевой И.А. — инструкция по развёртыванию и правкам

Готовый статический сайт по ТЗ «Техническое задание и контент» (дизайн: **«Сетевая топология»** + bento-плитки главной + светлые контентные страницы + точечные «консольные» акценты на страницах ПМ). Исходный сайт — в папке `site/`.

## 1. Что внутри (структура папки `site/`)

```
site/
├── index.html            — Главная (hero, показатели, узлы, новости, CTA)
├── about.html            — Обо мне (путь, образование, награды, подход)
├── disciplines.html      — Дисциплины 09.02.06 (карточки-порты ПМ/ОП)
├── disciplines/
│   ├── pm-01.html        — ПМ.01 Настройка сетевой инфраструктуры
│   ├── pm-02.html        — ПМ.02 Организация сетевого администрирования ОС
│   └── pm-03.html        — ПМ.03 Эксплуатация операционных систем
├── materials.html        — Учебные материалы (фильтры + поиск)
├── projects.html         — Проекты студентов (+ таблицы результатов)
├── method.html           — Методическая работа (ПК, выступления, жюри)
├── contacts.html         — Контакты + форма обратной связи
├── css/style.css         — единый файл стилей (цвета, шрифты — в начале файла)
├── js/main.js            — меню, фильтры материалов, форма
├── files/                — PDF-файлы материалов (сейчас заглушки!)
├── img/                  — фотографии (пока пусто, см. п.3.4)
├── .htaccess             — UTF-8, кэш, красивые URL
├── robots.txt            — для поисковиков
└── sitemap.xml           — карта сайта
```

## 2. Как развернуть сайт на Beget

### Шаг 1. Хостинг и домен
1. Зарегистрируйтесь на [beget.com](https://beget.com) и купите тариф (для такого сайта подойдёт любой базовый, включая бесплатный тестовый период).
2. В панели **Beget → «Домены»** подключите домен (например, `вашдомен.beget.site` — бесплатный поддомен, или свой платный домен). При покупке своего домена направьте DNS на NS-серверы Beget (`ns1.beget.com`, `ns2.beget.com`).
3. Дождитесь активации домена (обычно 5–30 минут для поддомена, до 24 ч для своего домена).

### Шаг 2. Загрузка файлов
**Вариант А — через файловый менеджер (проще):**
1. Beget-панель → раздел **«Файлы» → «Файловый менеджер»** (или FileZilla по FTP: хост = адрес сервера из панели, логин/пароль — из раздела «FTP»).
2. Откройте папку сайта — она называется так же, как ваш домен. Внутри есть папка `www` — это корень сайта.
3. **Удалите там дефолтный `index.php`** (стандартная страница Beget).
4. Загрузите **содержимое** папки `site/` (не саму папку, а всё, что внутри: `index.html`, `about.html`, `css/`, `js/`, `files/`, `img/`, `disciplines/`, `.htaccess`, `robots.txt`, `sitemap.xml`) прямо в `www`.
5. Проверьте: откройте `https://ваш-домен` — должна открыться главная страница.

⚠ Файл `.htaccess` — скрытый; включите показ скрытых файлов, при загрузке zip распаковывайте через «Извлечь в текущую папку».

**Вариант Б — через zip-архив:**
1. Заархивируйте содержимое `site/` в `site.zip`.
2. Файловый менеджер Beget → загрузите `site.zip` в `www` → правый клик → «Распаковать» → удалите архив.

### Шаг 3. HTTPS (зелёный замок)
1. Beget-панель → **«Домены и поддомены» → «SSL-сертификаты»**.
2. Нажмите «Установить бесплатный Let's Encrypt» для вашего домена.
3. Включите переключатель **«Принудительный редирект на HTTPS»**.

### Шаг 4. SEO-доводка
1. В файлах `robots.txt` и `sitemap.xml` замените `ВАШ-ДОМЕН` на реальное имя домена.
2. Зарегистрируйте сайт в [Яндекс.Вебмастере](https://webmaster.yandex.ru) и Google Search Console, отправьте sitemap.
3. Favicon: положите `favicon.ico` в корень `www`.

### Шаг 5. Резервное копирование (требование ТЗ)
- Beget делает ежедневные автоматические бэкапы (раздел «Резервные копии», хранение ~7 дней).
- Дополнительно раз в месяц скачивайте папку `www` архивом к себе на компьютер / Яндекс.Диск.

## 3. Как вносить правки без программиста

Все правки — обычный текст внутри HTML-файлов. Редактируйте **Блокнотом**, **Notepad++** или **VS Code** (сохраняйте в кодировке UTF-8!), затем загружайте изменённый файл тем же способом (файловый менеджер / FTP). Перед правкой сохраняйте копию файла.

### 3.1 Добавить новый учебный материал
Откройте `materials.html`, найдите `<div id="materials-grid">` и скопируйте в конец типовую карточку, изменив текст и ссылку:

```html
<div class="mat-card" data-type="pdf" data-disc="ОП.05">
  <div class="mat-icon t-pdf">PDF</div>
  <div><h3>Название материала</h3><span class="tag">ОП.05 · РП</span><br>
  <a class="dl" href="files/imya-fayla.pdf" download>Скачать →</a></div>
</div>
```
- `data-type` — тип для фильтра: `pdf | pres | lab | test | note | doc`;
- файл положите в папку `files/` (имя — латиницей, без пробелов);
- для больших файлов — залейте на Яндекс.Диск (общий доступ «кто знает ссылку») и вставьте ссылку:
  `<a class="dl" href="https://disk.yandex.ru/d/XXXX" target="_blank">Открыть на Яндекс.Диске →</a>`

### 3.2 Добавить новость/достижение на главную
В `index.html` найдите `<div class="news-list">` и добавьте строку:
```html
<div class="news-item"><time>2026-09</time><div>Текст события.</div></div>
```

### 3.3 Добавить дисциплину
В `disciplines.html` скопируйте блок `<div class="port-card">…</div>`:
- для ПМ используйте класс `badge-pm`, для ОП — `badge-op`;
- отдельная страница модуля: скопируйте `disciplines/pm-02.html` → `pm-XX.html`, поменяйте тексты, в карточке укажите `href="disciplines/pm-XX.html"`, добавьте страницу в `sitemap.xml`.

### 3.4 Поставить фотографию
1. Положите портрет в `img/photo.jpg` (~800×1000 px, до 300 КБ).
2. В `index.html` в hero замените `<div class="hero-photo">…заглушка…</div>` на:
```html
<img class="hero-photo" src="img/photo.jpg" alt="Соловцева Инна Александровна" style="object-fit:cover">
```

### 3.5 Заменить PDF-заглушки на реальные документы
В `files/` лежат пустые PDF-заглушки. Замените каждый своим файлом, **сохранив имя**: `wp-op-07.pdf`, `wp-op-06.pdf`, `wp-mdk-01-01.pdf`, `wp-mdk-01-02.pdf`, `wp-mdk-02-01.pdf`, `kim-tsi.pdf`, `kim-op-04.pdf`. Либо поменяйте ссылки в `materials.html`.

### 3.6 Изменить цвета/шрифты
Все они заданы один раз в начале `css/style.css` в блоке `:root`:
```css
--bg-dark: #0F172A;     /* графит hero */
--accent: #22D3EE;      /* электрик-циан */
--accent-lime: #A3E635; /* лайм */
```
Поменяли значение — обновился весь сайт. Шрифты (Unbounded, Golos Text, JetBrains Mono) подключаются ссылкой Google Fonts в `<head>` каждой страницы.

### 3.7 Телефон / e-mail / график консультаций
Левая колонка `contacts.html` (строки `E-mail`, `Телефон`, `График консультаций`). E-mail формы также указан в `js/main.js` (`mailto:inna742@ya.ru`).

### 3.8 Курс и форма обучения на страницах ПМ
В `disciplines/pm-0X.html` в блоке «Общая информация» есть ячейки с комментариями `<!-- укажите нужный -->` — замените значения на реальные.

### 3.9 Форма обратной связи
Сейчас форма работает без сервера: собирает письмо и открывает почтовую программу посетителя (mailto). Для отправки «на сервер» на Beget можно подключить PHP-обработчик или бесплатный сервис Formspree/FormSubmit — дорабатывается по запросу.
