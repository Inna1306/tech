# Сайт преподавателя Соловцевой И.А. — инструкция по развёртыванию и правкам

Готовый статический сайт по ТЗ «Техническое задание и контент» (дизайн: **«Сетевая топология»** + bento-плитки главной + светлые контентные страницы + точечные «консольные» акценты на страницах ПМ).

**Оформление:** на сайте оставлена одна цветовая тема — **фиолетовая** (`data-theme="violet"` на каждой странице). Переключатель тем из шапки удалён, зелёная палитра из CSS убрана. Менять тему не нужно — сайт всегда выглядит в фиолетовой палитре.

> **ВАЖНО:** папки `site/` или `www/` в репозитории **нет**. Все файлы сайта лежат **в корне репозитория** (`index.html`, `about.html`, `css/`, `js/` и т.д.). Именно содержимое корня загружается на хостинг в папку `www` (см. раздел 2).

## 2. Локальный просмотр (до публикации)

Сайт статический, поэтому посмотреть его можно двумя способами.

**Способ 1 — просто открыть файл.** Двойным щелчком откройте `index.html` в браузере. Интернет нужен только для загрузки шрифтов Google Fonts. Работает, но это не «настоящий» адрес.

**Способ 2 — локальный сервер (рекомендуется).** Тогда ссылки, `.htaccess`-подобное поведение и кодировки проверяются так же, как потом на хостинге:

| Инструмент | Команда (запускать из корня проекта) | Адрес в браузере |
|---|---|---|
| Python 3 | `python -m http.server 8000` | `http://localhost:8000` |
| PHP (встроенный сервер) | `php -S localhost:8000` | `http://localhost:8000` |
| Node.js / npx | `npx serve .` | адрес, который выведет утилита (обычно `http://localhost:3000`) |
| VS Code | расширение **Live Server** → правый клик по `index.html` → «Open with Live Server» | `http://127.0.0.1:5500/index.html` |

`localhost` / `127.0.0.1` — это ваш собственный компьютер; такой адрес видны только вам и недоступны из интернета.

## 3. Как выгрузить и опубликовать сайт на Beget

### Шаг 1. Хостинг и домен — где смотреть вкладки панели Beget
1. Зарегистрируйтесь на [beget.com](https://beget.com) и купите тариф (для такого сайта подойдёт любой базовый, включая бесплатный тестовый период).
2. Войдите в **панель управления Beget** (hosting.beget.com). Верхние вкладки, которые понадобятся:
   - **«Сайты»** (старое название — «Домены»; также есть подменю **«Список сайтов»**) — здесь создаётся сайт и виден его адрес;
   - **«Файлы» → «Файловый менеджер»** — здесь загружаются файлы сайта;
   - **«FTP»** — данные FTP-сервера, если будете грузить через FileZilla;
   - **«SSL» / «Домены и поддомены» → «SSL-сертификаты»** — включение HTTPS.
3. Во вкладке **«Сайты» → «Список сайтов» → «Добавить сайт»** укажите желаемое имя. Beget бесплатно даёт поддомен вида `имя.beget.tech` (ранее — `имя.beget.site`). Своё платное домен направьте на NS-серверы Beget (`ns1.beget.com`, `ns2.beget.com`). Дождитесь активации (поддомен — обычно 5–30 минут, свой домен — до 24 ч).

### Шаг 2. Загрузка файлов — куда и что класть
Корнем сайта на Beget является папка **`www`** внутри папки сайта (`/home/ваш_логин/public_html` она же отображается как `домен/www` в файловом менеджере). В репозитории папки `www` нет — её создавать на компьютере не нужно: `www` уже есть на хостинге.

**Вариант А — через файловый менеджер (проще):**
1. Панель Beget → **«Файлы» → «Файловый менеджер»** → откройте папку вашего сайта → войдите в `www`.
2. **Удалите там дефолтный `index.php`** (стандартная страница-заглушка Beget), иначе он может открываться вместо вашей главной.
3. Загрузите **содержимое корня репозитория** (не архив с папкой внутри, а сами файлы и папки: `index.html`, `about.html`, `disciplines.html`, `disciplines/`, `materials.html`, `projects.html`, `method.html`, `contacts.html`, `css/`, `js/`, `files/`, `img/`, `.htaccess`, `robots.txt`, `sitemap.xml`) прямо в `www`.
4. Проверьте: откройте адрес сайта из вкладки «Сайты» — должна открыться главная страница в фиолетовой теме.

⚠ Файл `.htaccess` — скрытый; включите «Показывать скрытые файлы» в настройках файлового менеджера и в FTP-клиенте. Если загружаете zip — распаковывайте правой кнопкой «Извлечь в текущую папку» и удаляйте лишнюю вложенную папку, чтобы `index.html` лежал непосредственно в `www`, а не в `www/site/`.

**Вариант Б — через zip-архив:**
1. В корне репозитория выделите ВСЕ файлы и папки (кроме самой папки `.git` и `README.md` — они на сайте не нужны) и заархивируйте в `site.zip` так, чтобы `index.html` был внутри архива «на верхнем уровне».
2. Файловый менеджер Beget → загрузите `site.zip` в `www` → правый клик → «Распаковать» → удалите архив.

**Вариант В — по FTP (FileZilla):**
1. Панель Beget → **«FTP»** (или раздел «Файлы» → «FTP-доступ»): скопируйте адрес FTP-сервера, логин и пароль (создайте отдельную FTP-учётную запись для сайта).
2. В FileZilla: «Хост» = адрес из панели, «Логин»/«Пароль» = из панели, порт 21. Подключитесь.
3. На сервере откройте `/домен/www` (или `/public_html`) и перетащите туда содержимое корня репозитория.

### Шаг 3. HTTPS (зелёный замок)
1. Панель Beget → **«Сайты» / «Домены и поддомены» → «SSL-сертификаты»**.
2. Нажмите «Установить бесплатный Let's Encrypt» для вашего домена.
3. Включите переключатель **«Принудительный редирект на HTTPS»**.

### Шаг 4. SEO-доводка
1. В файлах `robots.txt` и `sitemap.xml` замените `ВАШ-ДОМЕН` на реальное имя домена и загрузите обновлённые файлы в `www`.
2. Зарегистрируйте сайт в [Яндекс.Вебмастере](https://webmaster.yandex.ru) и Google Search Console, отправьте sitemap.
3. Favicon: положите `favicon.ico` в корень `www`.

### Шаг 5. Резервное копирование (требование ТЗ)
- Beget делает ежедневные автоматические бэкапы (раздел «Резервные копии», хранение ~7 дней).
- Дополнительно раз в месяц скачивайте папку `www` архивом к себе на компьютер / Яндекс.Диск.
- Ведите исходники в этом Git-репозитории: после правок делайте коммит — это ваша «эталонная» копия сайта.

## 4. Какой будет адрес сайта и где его найти

| Ситуация | Адрес | Где посмотреть |
|---|---|---|
| Бесплатный поддомен Beget | `https://имясайта.beget.tech` (у старых аккаунтов — `.beget.site`) | Панель Beget → вкладка **«Сайты» → «Список сайтов»** — там столбец с адресом каждого сайта |
| Свой домен (например, куплен у Reg.ru/Beget) | `https://вашдомен.рф` / `https://вашдомен.ru` | Там же, во вкладке «Сайты», после привязки домена |
| Временный доступ без домена | `http://имясайта.beget.tech` | Он же постоянный поддомен |
| Локальная проверка до публикации | `http://localhost:8000` (или другой порт из п.2) | Только на вашем компьютере, из интернета не видно |

Как проверить, что всё на месте: откройте адрес из вкладки «Сайты» — должен загрузиться `index.html`. Если открывается заглушка Beget — значит, не удалён `index.php` либо файлы заложены не в `www`, а в подпапку.

## 5. Как вносить правки без программиста

Все правки — обычный текст внутри HTML-файлов. Редактируйте **Блокнотом**, **Notepad++** или **VS Code** (сохраняйте в кодировке UTF-8!), затем загружайте изменённый файл в `www` тем же способом (файловый менеджер / FTP). Перед правкой сохраняйте копию файла. Тема оформления одна — фиолетовая; ничего переключать не нужно.

### 5.1 Добавить новый учебный материал
Откройте `materials.html`, найдите `<div id="materials-grid">` и скопируйте в конец типовую карточку, изменив текст и ссылку:

```html
<div class="mat-card" data-type="pdf" data-disc="ОП.05">
  <div class="mat-icon t-pdf">PDF</div>
  <div><h3>Название материала</h3><span class="tag">ОП.05 · РП</span><br>
  <a class="dl" href="files/imya-fayla.pdf" download>Скачать →</a></div>
</div>
```
- `data-type` — тип для фильтра: `pdf | pres | lab | test | note | doc`;
- файл положите в папку `files/` (имя — латиницей, без пробелов);
- для больших файлов — залейте на Яндекс.Диск (общий доступ «кто знает ссылку») и вставьте ссылку:
  `<a class="dl" href="https://disk.yandex.ru/d/XXXX" target="_blank">Открыть на Яндекс.Диске →</a>`

### 5.2 Добавить новость/достижение на главную
В `index.html` найдите `<div class="news-list">` и добавьте строку:
```html
<div class="news-item"><time>2026-09</time><div>Текст события.</div></div>
```

### 5.3 Изменить тексты обращения и «Обо мне»
Все личные тексты уже ввёрстаны, править их можно прямо в HTML:
- **Первый экран (обращение)** — `index.html`, блок `<div class="hero-greeting">…</div>` (три абзаца) и `<h1>`/`<p class="subtitle">` над ним;
- **Карточка-продолжение обращения** — `index.html`, `<div class="prose-card">` сразу после hero;
- **«О работе кратко»** — два блока «О пути» / «О том, как я учу» в `index.html` (класс `about-duo`);
- **«О студентах и результатах»** — `index.html`, карточка `prose-card` после списка новостей;
- **«Что вы найдёте на сайте»** — список `<ul class="find-list">` на главной и в `about.html`;
- **Финальный призыв** — `index.html`, блок `<div class="cta-band">` (тексты в `<p class="cta-text">`);
- **Страница «Обо мне»** — полный текст-размышление в `about.html`, раздел 1 (блок `<div class="essay">`), далее «О студентах», «Что вы найдёте», путь по годам, образование, награды, подход, школьный опыт и «Приглашение».

Стилы этих блоков: `.hero-greeting`, `.prose-card`, `.about-duo`, `.find-list`, `.cta-text`, `.essay` в `css/style.css`.

### 5.4 Добавить дисциплину
В `disciplines.html` скопируйте блок `<div class="port-card">…</div>`:
- для ПМ используйте класс `badge-pm`, для ОП — `badge-op`;
- отдельная страница модуля: скопируйте `disciplines/pm-02.html` → `pm-XX.html`, поменяйте тексты, в карточке укажите `href="disciplines/pm-XX.html"`, добавьте страницу в `sitemap.xml`.

### 5.5 Поставить фотографию
1. Положите портрет в `img/photo.jpg` (~800×1000 px, до 300 КБ).
2. В `index.html` в hero замените `<div class="hero-photo">…заглушка…</div>` на:
```html
<img class="hero-photo" src="img/photo.jpg" alt="Соловцева Инна Александровна" style="object-fit:cover">
```

### 5.6 Заменить PDF-заглушки на реальные документы
В `files/` лежат PDF-файлы. Замените каждый своим документом, **сохранив имя**: `wp-op-07.pdf`, `wp-op-06.pdf`, `wp-mdk-01-01.pdf`, `wp-mdk-01-02.pdf`, `wp-mdk-02-01.pdf`, `kim-tsi.pdf`, `kim-op-04.pdf`. Либо поменяйте ссылки в `materials.html`.

### 5.7 Изменить цвета/шрифты
Фиолетовая тема задана один раз в начале `css/style.css` в блоке `:root`:
```css
--accent-strong: #6D28D9;  /* основной фиолетовый */
--accent-second: #2563EB;  /* синий второй акцент */
--footer-bg: #241B4D;      /* цвет подвала */
```
Поменяли значение — обновился весь сайт. Шрифты (Unbounded, Golos Text, JetBrains Mono) подключаются ссылкой Google Fonts в `<head>` каждой страницы.

### 5.8 Телефон / e-mail / график консультаций
Левая колонка `contacts.html` (строки `E-mail`, `Телефон`, `График консультаций`). E-mail формы также указан в `js/main.js` (`mailto:inna742@ya.ru`).

### 5.9 Курс и форма обучения на страницах ПМ
В `disciplines/pm-0X.html` в блоке «Общая информация» есть ячейки с комментариями `<!-- укажите нужный -->` — замените значения на реальные.

### 5.10 Форма обратной связи
Сейчас форма работает без сервера: собирает письмо и открывает почтовую программу посетителя (mailto). Для отправки «на сервер» на Beget можно подключить PHP-обработчик или бесплатный сервис Formspree/FormSubmit — дорабатывается по запросу.
